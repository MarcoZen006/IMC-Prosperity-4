IMC Prosperity is a global, gamified, virtual trading competition run by 
IMC Trading (https://www.imc.com/), one of the world's largest
market-making firms. The 2026 edition (Prosperity 4) ran April 14–30 across five
consecutive rounds, with 22,130 teams from 400+ universities competing worldwide.

Each round has two components:

- **Algorithmic trading** — a Python bot submitted to a live simulated exchange,
  competing in real time against other bots and market makers across a shared
  order book. Performance is measured in **XIRECs**, the competition's currency.
- **Manual trading** — a one-shot decision problem released mid-round: sealed-bid
  auctions, options portfolios, portfolio allocation puzzles, and game-theoretic
  bidding scenarios. You have hours to analyse, model, and submit. There are no
  second chances.

  You can find each of these in its respective folder as well as a summary explaining
  the quantatative, stocastic, economic and mathematical techniques used.
